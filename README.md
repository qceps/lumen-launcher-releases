# Lumen Launcher — sürümler

Bu repo yalnızca **Lumen Launcher** kurulum dosyalarını ve otomatik güncellemeleri barındırır.
Kaynak kod ayrı ve private bir repodadır.

## Kurulum

[Releases](https://github.com/qceps/lumen-launcher-releases/releases/latest) sayfasından en son
`Lumen-Launcher-Setup-<sürüm>.exe` dosyasını indirip çalıştır. Bundan sonraki sürümler launcher
açıkken kendiliğinden indirilir; hazır olunca "Yeniden başlat" ile kurulur.

> Windows SmartScreen "tanınmayan uygulama" uyarısı verirse **Ek bilgi → Yine de çalıştır** de
> (kurulum dosyası imzalı değil).
